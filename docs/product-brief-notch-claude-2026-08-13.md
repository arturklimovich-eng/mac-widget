# Product Brief: NotchClaude

**Дата:** 2026-08-13
**Автор:** Artur
**Статус:** MVP реализован

## Краткое описание

NotchClaude — macOS-виджет, который живёт в чёлке MacBook и по наведению курсора
показывает, чем сейчас занят Claude Code и сколько токенов уже израсходовано:
за 5-часовое окно лимитов, за сегодня и за текущую сессию. Данные читаются из
локальных логов Claude Code, сеть не используется.

## Проблема

Claude Code расходует лимиты в скользящем 5-часовом окне, но узнать текущее
состояние можно только вручную — в терминале или через сторонние утилиты. На
практике это выливается в две неприятности:

1. Лимит заканчивается неожиданно, посреди работы, без предупреждения.
2. Непонятно, работает ли агент прямо сейчас или уже давно ждёт ввода, — если
   окно терминала не на переднем плане, приходится переключаться и смотреть.

Отдельного индикатора «сколько осталось» в Claude Code нет, а сторонние
дашборды требуют либо API-ключа, либо отправки данных наружу.

## Пользователь

Один пользователь — автор проекта. Разработчик на MacBook с чёлкой, весь день
держит запущенным Claude Code, часто параллельно с другими задачами, и хочет
видеть состояние агента и расход лимитов боковым зрением, не переключая окна.

Никакой мультипользовательности, синхронизации или установки для других людей в
задаче нет.

## Решение

Агент-приложение (`LSUIElement`, без иконки в Dock). Прозрачная `NSPanel` лежит
поверх чёлки и в свёрнутом виде невидима. При наведении курсора на чёлку панель
раскрывается вниз и показывает:

- активен Claude или простаивает (по свежести последней записи в логах);
- расход токенов за скользящее 5-часовое окно + число ответов модели;
- расход за сегодня;
- расход текущей сессии + имя проекта;
- текущую модель;
- кнопку «Выход».

Курсор ушёл — панель свернулась. Никаких клавиатурных сокращений, иконок в
меню-баре и настроек: жест «мышь в чёлку» и есть весь интерфейс.

Источник данных — локальные логи Claude Code
`~/.claude/projects/<project>/<session>.jsonl`. Ни сети, ни разрешений macOS
(доступность, экран, диск) не требуется; ничего не отправляется наружу.

## MVP-скоуп

- Чтение и агрегация логов Claude Code (окно 5 ч, сегодня, сессия, дедуп
  повторных записей одного запроса).
- Геометрия чёлки: определение экрана с чёлкой и её точных границ.
- Раскрытие/сворачивание панели по наведению, обновление данных раз в 3 секунды
  пока панель раскрыта.
- Индикатор активности, модель, имя проекта, кнопка выхода.
- Самопроверка парсера (`--selftest`) и печать снимка по реальным логам
  (`--dump`).
- Сборка `.app` одним скриптом (`bundle.sh`).

## Вне скоупа

- Оценка расхода в деньгах (нужна и требует поддержки таблица цен моделей).
- Автозапуск при входе в систему.
- Экран настроек, темы, кастомизация вида.
- Графики и история расхода за прошлые дни/недели.
- Инкрементальное чтение логов (сейчас файлы перечитываются целиком).
- Одновременная поддержка нескольких экранов с чёлкой.
- Уведомления и предупреждения о приближении к лимиту.
- Распространение: подпись Developer ID, нотаризация, установщик, Homebrew.

## Критерии успеха

| Критерий | Цель |
| --- | --- |
| Ответ на «сколько осталось» | Без переключения окон, одним движением мыши |
| Задержка раскрытия | Ощущается мгновенной (анимация 0.15 с) |
| CPU в простое | Практически нулевой: свёрнутая панель не опрашивает логи |
| Приватность | Ноль сетевых запросов и ноль запросов разрешений macOS |
| Стоимость сопровождения | Ноль сторонних зависимостей, ~450 строк Swift |
| Установка | `./bundle.sh && open build/NotchClaude.app` |

Проект считается успешным, если автор оставляет его запущенным постоянно и
перестаёт лезть в терминал за статусом расхода.
